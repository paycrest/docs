Paycrest works in both directions: off-ramp (stablecoins to local currency) and on-ramp (local currency to stablecoins). The scenarios below show common ways businesses use it. For code, see the [Sender API Integration](/implementation-guides/sender-api-integration) guide.

## Crypto Businesses

### DeFi Payouts

**Overview:** Enable DeFi protocols to pay out yields and rewards directly to users' bank accounts.

**How it works:**
- DeFi protocols integrate directly with Paycrest Gateway contract
- Users receive stablecoin rewards from yield farming, staking, or trading
- Protocol automatically converts rewards to fiat and sends to user's bank account
- No manual withdrawal process required

**Benefits:**
- Automated payout system reduces operational overhead
- Users receive funds in their preferred local currency
- Eliminates need for users to manage crypto-to-fiat conversion
- Improves user experience and retention
- Direct smart contract integration for better composability

**Example Implementation:**
```javascript
// DeFi protocol payout using Gateway contract
const gateway = new Contract(gatewayAddress, gatewayAbi, signer);

const payoutOrder = await gateway.createOrder(
  usdtAddress,
  parseUnits('150.00', 6),
  rate,
  ZeroAddress,
  0,
  refundAddress,
  messageHash
);
```

### Wallet and App On-ramp

**Overview:** Let users buy stablecoins with local currency from inside a wallet or app.

**How it works:**
- The app creates an on-ramp order through the Sender API from its backend
- The user pays the exact amount shown into the provider's local account
- Once the provider confirms the payment, stablecoins are delivered to the user's wallet on-chain
- If the payment can't be completed, it is refunded to the user's account

**Benefits:**
- Users fund their wallets without leaving the app
- One all-in rate quoted before the user pays
- The same integration also handles off-ramp

## Getting Started

To implement any of these use cases:

1. **Sign up** as a sender at [app.paycrest.io](https://app.paycrest.io)
2. **Complete KYB** for your business
3. **Get API credentials** from your dashboard
4. **Integrate the Sender API**: start with the [Quickstart](/quickstart), then the [Sender API Integration](/implementation-guides/sender-api-integration) guide
5. **Test** with small amounts ($0.50 minimum on most networks)
6. **Go live**

<Warning>
  Call the Sender API from your backend. Never put your API key or secret in a browser or mobile app.
</Warning>
