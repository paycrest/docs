Paycrest supports three stablecoins across nine blockchain networks (seven EVM chains plus Starknet and Tron). Use the [GET /tokens](/api-reference/general/list-supported-tokens) endpoint for the live list including contract addresses, decimals, and network availability.

**Solana** is a **bridged network**: off-ramp deposits and on-ramp deliveries are accepted there, while the order settles on a native network. `GET /tokens` lists a Solana token only while at least one bridge direction is live for it, and does not say which; check a direction with the [rates endpoint](/api-reference/general/get-token-rate) (`side=sell` for off-ramp, `side=buy` for on-ramp). See [Bridged networks](/implementation-guides/bridged-networks).

## Network Configuration

When creating orders, specify the stablecoin and network using the `token` and `network` parameters (v1) or via the `source`/`destination` objects (v2). Use **`starknet`** for Starknet and **`tron`** for Tron.

<Tabs>
  <Tab title="v2 API (recommended)">
```javascript
// Offramp: USDT on Base → NGN bank account
const order = {
  amount: "100",
  source: {
    type: "crypto",
    currency: "USDT",
    network: "base",
    refundAddress: "0xYourAddress"
  },
  destination: {
    type: "fiat",
    currency: "NGN",
    recipient: {
      institution: "GTBINGLA",
      accountIdentifier: "1234567890",
      accountName: "John Doe",
      memo: "Payment"
    }
  }
};
```
  </Tab>
  <Tab title="v2 Starknet off-ramp">
```javascript
// Offramp: USDT on Starknet → NGN bank account

};
```
  </Tab>

  </Tab>
  <Tab title="v1 API (legacy)">

<Note>
  **Starknet addresses** are felt-sized hex strings (`0x` + 63–64 hex digits). Do not use EVM checksum formatting. The zero address is rejected.

  **Tron addresses** are Base58Check and start with `T`. Do not pass EVM `0x` addresses when `network` is `tron`.

  **Solana addresses** (bridged network) are Base58 public keys, 32–44 characters. On off-ramp, `refundAddress` must be a Solana address when `network` is `solana`. On on-ramp, `destination.recipient.address` must be a Solana address when `destination.recipient.network` is `solana`, and that wallet must already have a token account for the stablecoin's mint.
</Note>

## API Endpoints

- **[GET /tokens](/api-reference/general/list-supported-tokens)** — Live list of all supported stablecoins with contract addresses, decimals, and network identifiers
- **[GET /rates](/api-reference/general/get-token-rate)** — Get the current exchange rate for a token/amount/fiat pair

<Note>
  Always retrieve the `decimals` value from the API before constructing token transfer transactions. Do not hardcode decimal values, as BNB Smart Chain USDT and USDC use 18 decimals while all other supported networks use 6.
</Note>
